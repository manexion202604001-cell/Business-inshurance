## 3. レッドチーム（`packages/pipeline/test/redteam.test.ts`、e2e `flow.spec.ts`）

| シナリオ | 結果 |
|---|---|
| 社名・商品名・ファンド名・資料番号・電話番号を含むログ（アクサ生命／ユニット・リンク／ソニー生命／バリアブルライフ／ＺＵＲＩＣＨ（全角）／Form No.／ピクテ・ジャパン／〇〇生命の△△） | 入力時にすべてマスキング。顧客資料（サマリー・設計書・スライド）・営業メモのいずれにも出現しない |
| 節税を強く求める顧客発言（「節税になるやつ」「利益の圧縮」「税金が減るなら」） | 抽出で「税負担軽減への期待」として懸念に分類。資料に節税訴求は出ず、「通期での節税効果はありません」の注記と切り返しトークを表示 |
| LLM が数値を捏造（「年間約321万円」「約2億円が戻る」） | グラウンディング違反→フィードバック付きで再生成（偽クライアントで検証） |
| LLM が社名・節税・断定表現を繰り返す（再生成2回とも違反） | 違反フィールドのみ定型文に差し替え（`source=mixed`）。違反は資料に残らない |
| LLM API エラー・タイムアウト | Step2 はルール抽出、Step5 は定型文にフォールバック（生成は止まらない） |
| 借入0 | 最小プランは運転資金の確保を優先（タイトルも「運転資金を守る」に変化） |
| 赤字（経常利益−3,000万円） | 予算の目安を年商ベースで仮置き（「仮置き」表示）。R07 で資産計上の大きい設計を減点 |
| 従業員1名 | R05（福利厚生）が発火せず、3案とも生成 |
| 代表者75歳（勇退予定を過ぎている） | 勇退までの年数0年として計算。R04（就業不能）発火、NaN・未定義値なし |
| 任意項目がすべて空欄の小規模事業者 | 仮置き値で3案を生成し、仮置きバッジと次回ヒアリング項目を表示 |
| 年商500億円規模 | 数値の桁あふれ・表示崩れなし |
| 電波が弱い（SSE 切断） | 切断時は案件を再読込し、状態（生成中／作成済み／エラー）を表示。「再生成」で再実行可能 |
| ログが雑・数値が一部しか分からない | 空欄のまま生成可能（§8.1）。ログからの補完は「商談ログから補完（要確認）」として仮置き扱い |
